# 다빈치 코드 (Da Vinci Code) 온라인 게임

브라우저에서 바로 하는 다빈치 코드 보드게임입니다. 빌드가 필요 없는 정적 사이트(`index.html` 하나)입니다.

## 게임 방식

- 🤖 **AI 대전**: 2~4명(나 + AI), 4명이면 2:2 팀전도 가능. AI 난이도는 쉬움, 보통, 어려움 중에서 고릅니다.
- 👥 **한 화면**: 2~4명이 한 기기에서 번갈아 플레이합니다. 차례가 바뀔 때 화면을 가려줍니다. AI를 섞을 수 있어요. 예: 사람 2 + AI 1, 사람 3 + AI 1, 사람 2 + AI 2.
- 🤝 **팀 구성**: 4명 팀전에서 사람 2 + AI 2면 '사람 팀 vs AI 팀' 또는 '사람+AI 섞기'를 고를 수 있습니다(한 화면, 온라인).
- 🌐 **온라인**: 방을 만들고 초대 링크를 보내면 다른 기기에서 참가합니다. 최대 4명이고 로그인은 필요 없습니다(PeerJS P2P). 빈 자리는 AI로 채워 바로 시작할 수 있고, 중간에 나간 사람은 AI가 대신합니다.
- 🧩 **퍼즐**: AI가 숨긴 코드를 최소 오답으로 맞히는 혼자 하기 모드입니다. 📅 **오늘의 문제**는 날마다 모두에게 같은 문제가 나오고, 결과를 복사해 공유할 수 있습니다.

## 덱

| 덱 | 내용 |
|---|---|
| 기본 숫자 | 0~7 / 0~11 / 0~15, 흰·검 |
| 배수 | 2~9의 배수 12개 (예: 3의 배수 0~33) |
| 나머지 색깔 | 0~23, 3으로 나눈 나머지가 색 (빨0·파1·초2) |
| 듬성듬성 | 2·3의 배수만 (2,3,4,6,8,9,10,12,14,15,16,18) |
| 소수 | 2~37 |
| 알파벳 | A~M, 흰·검 |
| 한글 자음 | ㄱ~ㅎ, 흰·검 |

## 옵션

- **시작 타일**: 자동(2~3명 4개, 4명 3개) / 3 / 4 / 5
- **조커**: 0 / 2 / 4
- **타이머**: 끔 / 20초 / 40초. 시간이 지나면 오답으로 처리됩니다.
- **홀짝 표시**: 숨긴 타일에 홀/짝(알파벳은 모음/자음)을 표시합니다. 이때 조커는 빠집니다.
- **질문 찬스**: 한 판에 1번 "이 타일이 ○보다 큰가요?"를 물을 수 있습니다.
- **하드코어**: 틀리면 타일을 1개 더 공개합니다.

## 배포 (Vercel)

Vercel에서 이 저장소를 Import한 뒤 설정을 바꾸지 않고 Deploy하면 됩니다. 이후 `main`에 푸시하면 자동으로 다시 배포됩니다.
