# 다빈치 코드 (Da Vinci Code) 온라인 게임

브라우저에서 바로 하는 다빈치 코드 보드게임입니다.

- 🤖 **AI 대전**: 컴퓨터와 1:1 대결 (쉬움 / 보통 / 어려움)
- 👥 **2인 대전**: 한 화면에서 번갈아 플레이
- 🌐 **온라인 대전**: 방을 만들고 초대 링크를 보내면 다른 기기에서 바로 참가 (로그인 필요 없음, PeerJS P2P 연결)

## 배포 (Vercel)

빌드가 필요 없는 정적 사이트입니다. Vercel에서 이 저장소를 Import한 뒤 설정을 바꾸지 않고 Deploy하면 됩니다.

## 규칙 요약

1. 흰색·검은색 숫자 타일(0~11) 24개 중 각자 4개씩 가져가고, 작은 수가 왼쪽에 오도록 정렬합니다. 같은 숫자면 검은색이 왼쪽입니다.
2. 내 차례에 타일을 1개 가져온 뒤, 상대의 숨겨진 타일 하나의 숫자를 추리합니다.
3. 맞히면 그 타일이 공개되고, 계속 추리하거나 차례를 마칠 수 있습니다. 틀리면 이번에 가져온 내 타일이 공개됩니다.
4. 조커(–)는 원하는 자리에 놓을 수 있고, 한 번 놓으면 옮길 수 없습니다.
5. 상대의 타일을 모두 먼저 공개시키면 승리합니다.
